การเริ่มต้นใช้งาน

เอกสารนี้อธิบายวิธีเรียกใช้งาน iApp AI API แต่ละ method พร้อม parameter ที่ต้องส่ง ตัวอย่างโค้ด และ response ที่จะได้รับ

Base URLhttps://api.iapp.co.th
Authenticationส่ง API Key ผ่าน HTTP header: apikey: <YOUR_API_KEY>
รูปแบบ requestPOST (ยกเว้นที่ระบุไว้เป็นอย่างอื่น)
รูปแบบ responseJSON ทุก endpoint
หน่วยเครดิตIC (iApp Credit) — หักต่อการเรียกแต่ละครั้งตามที่ระบุในแต่ละ method
วิธีติดตั้ง Python SDK
pip install iapp-ai
ตัวอย่างการ authenticate
from iapp_ai import api
client = api("YOUR_API_KEY")

หมายเหตุ: สถานะ ✅ Live-verified หมายความว่า iApp ได้ทดสอบ endpoint จริงและได้รับ HTTP 200 แล้ว

📖 API Reference
1
face_liveness
ตรวจสอบว่ารูปภาพใบหน้าเป็นบุคคลจริง (Real) หรือภาพลอกเลียนแบบ (Spoof) เหมาะสำหรับขั้นตอน eKYC Passive Liveness
หมวดหมู่eKYC
EndpointPOST /v3/store/ekyc/face-passive-liveness
Authenticationapikey: <YOUR_API_KEY>
ค่าใช้จ่าย1 IC ต่อการเรียก 1 ครั้ง
สถานะการทดสอบ✅ ทดสอบแล้ว (16 มิถุนายน 2569)
พารามิเตอร์
พารามิเตอร์ชนิดข้อมูลจำเป็นค่าเริ่มต้นคำอธิบาย
file_pathstrจำเป็น—พาธของไฟล์รูปภาพใบหน้า (JPG/PNG ≤ 10 MB)
headersDict[str,str]ไม่จำเป็นNoneHTTP headers เพิ่มเติม
data_payloadDict[str,Any]ไม่จำเป็นNoneพารามิเตอร์ form-data เพิ่มเติม
filesList[Any]ไม่จำเป็นNoneไฟล์เพิ่มเติมที่ต้องการอัปโหลด
ค่าที่ได้รับกลับ
JSON ประกอบด้วย: filename, predict (REAL/SPOOF), score, darkness, data, normalized, taskGuid
ตัวอย่างการใช้งาน
python
from iapp_ai import api
import iapp_ai.module_api as module_api

client = api("YOUR_API_KEY")
resp = client.face_liveness("img/selfie.jpg")
print(resp.json()["predict"])   # REAL หรือ SPOOF
print("taskGuid:", module_api.taskGuid)
ตัวอย่าง response (HTTP 200)
{
  "filename": "selfie.jpg",
  "predict": "SPOOF",
  "score": 0.611,
  "darkness": 0,
  "data": { "SPOOF": 0.720, "REAL": 0.280 },
  "taskGuid": "f81d4fae-7dec-11d0-a765-00a0c91e6bf6"
}
รหัสข้อผิดพลาด
HTTP Statusความหมายวิธีแก้ไข
400/422รูปแบบหรือขนาดไฟล์ไม่ถูกต้องใช้รูป JPG/PNG ขนาดไม่ต่ำกว่า 200x200 px
402เครดิตไม่เพียงพอเติม IC ในระบบก่อนเรียกใช้งาน

หมายเหตุ (C-1)
ในรุ่นก่อนมีบั๊กที่เก็บ HTTP Response ทั้งก้อนไว้ใน taskGuid ปัจจุบันแก้ไขแล้ว — ดึงเฉพาะค่า String ของ ID เพื่อนำไป Polling ต่อใน info_face_liveness ได้อย่างถูกต้อง

face_id_card_verification
เปรียบเทียบรูป selfie กับรูปหน้าบนบัตรประชาชน เพื่อยืนยันว่าเป็นบุคคลเดียวกัน เหมาะสำหรับขั้นตอน eKYC
หมวดหมู่eKYC
EndpointPOST /v3/store/ekyc/face-and-id-card-verification
ค่าใช้จ่าย1 IC ต่อการเรียก 1 ครั้ง
สถานะการทดสอบ⚠️ ยังไม่ได้ทดสอบกับข้อมูลจริง (ต้องใช้รูปบัตรและ selfie จริง)
พารามิเตอร์
พารามิเตอร์ชนิดข้อมูลจำเป็นค่าเริ่มต้นคำอธิบาย
id_card_pathstrจำเป็น—path ของไฟล์รูปบัตรประชาชน (JPG/PNG ขนาดอย่างน้อย 600x400 px ไม่เกิน 10 MB)
selfie_pathstrจำเป็น—path ของไฟล์รูป selfie (เงื่อนไขเดียวกับรูปบัตร)
headersDict[str,str]ไม่จำเป็นNoneHTTP headers เพิ่มเติม
data_payloadDict[str,Any]ไม่จำเป็นNoneพารามิเตอร์ form-data เพิ่มเติม
filesList[Any]ไม่จำเป็นNoneไฟล์เพิ่มเติม
ค่าที่ได้รับกลับ
JSON ประกอบด้วยค่า confidence ของแต่ละรูปและค่ารวม รวมถึงผล isSamePerson (true/false)
ตัวอย่างการใช้งาน
python
# ⚠️ ต้องสลับอาร์กิวเมนต์ — ดูข้อควรทราบด้านล่าง
resp = client.face_id_card_verification(
    id_card_path="img/selfie.jpg",   # ส่ง selfie เป็น file0
    selfie_path="img/idcard.jpg"    # ส่ง ID card เป็น file1
)
print(resp.json()["isSamePerson"])
ตัวอย่าง response (HTTP 200)
{ "isSamePerson": true, "confidence": 0.98 }
รหัสข้อผิดพลาด
HTTP Statusความหมายวิธีแก้ไข
400/422รูปขนาดเล็กเกินไปหรือรูปแบบไฟล์ไม่รองรับใช้รูป JPG หรือ PNG ขนาดอย่างน้อย 600x400 px
402เครดิตไม่เพียงพอเติม IC ในระบบก่อนเรียกใช้งาน
⚠️
ข้อควรทราบ — Parameter Swap Bug
Method นี้ต่างจาก face_verification ตรงที่ใช้เปรียบเทียบ selfie กับรูปที่ปรากฏบนบัตรประชาชนโดยเฉพาะ อย่างไรก็ตาม SDK รุ่นปัจจุบัน: backend คาดหวัง file0 = selfie และ file1 = ID card แต่ parameter ชื่อ id_card_path ถูก map ไปที่ file0 — ดังนั้น จำเป็นต้องสลับอาร์กิวเมนต์ ตามตัวอย่างด้านบน
🚫 รหัสข้อผิดพลาดทั่วไป
HTTP Statusความหมายวิธีแก้ไข
400ส่งข้อมูลผิดรูปแบบตรวจสอบชนิดและชื่อ field ให้ถูกต้อง
401API Key ไม่ถูกต้องหรือไม่ได้ส่งมาตรวจสอบ API Key อีกครั้ง
402เครดิตไม่เพียงพอเติม IC ในระบบก่อนเรียกใช้งาน
421Company name หรือ password ไม่ถูกต้องตรวจสอบ credentials ของ Company
422ข้อมูลไม่ผ่านการตรวจสอบตรวจสอบว่าส่ง field ที่จำเป็นครบแล้ว
424ขนาดใบหน้าเล็กเกินไปใช้รูปที่ใบหน้าชัดเจน ไม่ถูกบดบัง
500Server errorรอแล้วลองใหม่ หรือตรวจสอบรูปแบบ/ขนาดไฟล์
